# Loader

Репозиторий публичный, со случайным именем. Ключ для запуска не требуется.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/nikkon-lol/r-3a6a7779c88c35a335eedf76cec69dd2/main/main.lua"))()
```

Сохрани эту команду в исполнителе. Она скачивает `main.lua` из ветки `main` при каждом запуске. Для обновления меняется содержимое `main.lua`; ссылка сохраняется.

Текущая версия: Autobuild Studio v5 / ORBIT, обновление stairwell-20. Управление и возможности — [GUIDE.md](GUIDE.md).

Файл `loader.lua` содержит ту же команду. Старый вариант с личным ключом больше не требуется. Случайное имя не ограничивает доступ: репозиторий виден в профиле владельца, а файлы доступны любому со ссылкой.

Для наблюдения за анимациями обычного Build:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/nikkon-lol/r-3a6a7779c88c35a335eedf76cec69dd2/main/animation-probe.lua"))()
```

Тест сам не строит и не проигрывает анимации. Возьми настоящий Build, постой с ним, поставь 3–5 блоков вручную, затем нажми «Завершить и скопировать». Отчёт также сохраняется в `Autobuild-animation-report.txt`.

Для проверки земли и наблюдения за ручной работой лопатой:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/nikkon-lol/r-3a6a7779c88c35a335eedf76cec69dd2/main/shovel-probe.lua"))()
```

Порядок тестов — [SHOVEL-TEST.md](SHOVEL-TEST.md). Наблюдатель сам не копает и не отправляет команды. Автоматические действия лопатой ещё не включены. План строительства теперь отрисовывается стрелками во время самого расчёта.

Выключить ORBIT без перезахода, сохранив постройки и данные:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/nikkon-lol/r-3a6a7779c88c35a335eedf76cec69dd2/refs/heads/main/unload.lua"))()
```


«Приколы» → Unanchor → «Двойник R6»: мини-окно с четырьмя формами: R6 (6), кубики 1×1×1 (13), кубики ×2 (104), каменный голем (104). Маленькая кубическая голова, местная прозрачность 20%, проход сквозь детали, повторение поз, отступ и сторона. «Остановить» полностью забывает старые формы и ожидающие CanCollide. Новое создание всегда получает новый ID и приоритет после отмены. Защита от потери управления приближает модель при появлении других игроков; «Вернуть контроль» временно подводит персонажа к своим деталям и возвращает на место. Нужны R6 и настоящие Build/Paint/Shape. Перед закрытием основного окна нажми «Припарковать оставшиеся». Подробности и ограничения — [GUIDE.md](GUIDE.md).

После запуска двойника — тридцатисекундная проверка без команд:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/nikkon-lol/r-3a6a7779c88c35a335eedf76cec69dd2/refs/heads/main/companion-probe.lua"))()
```

Отчёт появится в F9, буфере обмена и `Orbit-companion-report.txt`. Во время проверки походи, попрыгай, повернись и поменяй отступ.


«Приколы» → Генераторы → Stairwell: открытый вход перед игроком на уровне ног, основной маршрут только вверх или по ровным коридорам, редкий свет 1×1×1. Этаж 20 и дальше чёрные. Геометрия и шаблонный план находятся в памяти мини-окна без вкладок и сохранений. Генерация заменяет прежнее превью; доступны другой вариант, удаление превью, пауза и продолжение. Каждый этаж завершается и проверяется до следующего. Проверки пинга/FPS и препятствий сохраняются; чужие блоки не удаляются. Подробнее — [GUIDE.md](GUIDE.md).
